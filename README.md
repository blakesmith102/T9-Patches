A series of speedrunning patches for BOCW(T9) 

To inject these patches go to https://github.com/ate47/atian-cod-tools/releases
- download version 2.22.0 of acts.zip
- extract to location
- open bin
- open acts-ui.exe
- it will automatically update to latest version
- go to GSC Inject
- open the desired patch in file location
- boot BOCW and be in the zombies main menu
- hit Inject PC Script
- load game

DoublePointPatch - Makes first drop of your game a double points

DieCoffin - Makes whatever weapon you pickup after completing the coffin dance side ee a Die Shockwave, and makes first drop of your game a double points

ForsakenBoxLocation - Makes the game give you the best box location for easter egg speedruns

ForsakenBoxPatch - Gaurentees the best box location, a double points as the first drop, and makes whatever weapon you pickup from the box the Crysallaxe

MauerApartmentsBoxPatch - Makes the game give you the apartments box location first

MauerCansPatch - Gives you perfect cans for easter egg speedruns

MauerBoxPatch - Gives you apartments box location and makes whatever weapon you pickup from the box the CRBRS

MauerBoxCansPatch - Gives you apartments box location, first hit CRBRS, and perfect cans

PositionTracker - Displays the coordinates of your character
