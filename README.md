A series of speedrunning patches for BOCW(T9) 

To inject these patches go to https://github.com/ate47/atian-cod-tools/releases
- download the latest version of acts.zip
- extract to location
- open bin
- open acts-ui.exe
- go to GSC Inject
- open the desired patch in file location
- boot BOCW and be in the zombies main menu
- hit Inject PC Script
- load game

DoublePointPatch.gscc - Makes first drop of your game a double points

DieCoffin.gscc - Makes whatever weapon you pickup after completing the coffin dance side ee a Die Shockwave, and makes first drop of your game a double points
